# Security policy

## Reporting a vulnerability

Report it privately: use **Report a vulnerability** on this repository's Security tab, or reach the
owner through his GitHub profile. Please do not open a public issue for it.

Never post a key, a token, a password, a `.env` file or SecondBrain's settings in an issue, a pull
request or a report. If you have found one exposed, say where it is, not what it is.

## Scope

SecondBrain runs on the owner's PC. Security-relevant areas: the MCP server and its keys (Settings,
Share), the approval cards, the integrations on the owner's own accounts, the notes vault (personal,
never committed) and the provenance chain's integrity.
